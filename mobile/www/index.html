Bloop is waiting for the HabitFlow server

This app is a native shell around the HabitFlow web app — it wakes up as soon as it can reach your server. To get going:

  1. On your PC, start HabitFlow with npm run dev -- -H 0.0.0.0 (or deploy it — see MOBILE.md).
  2. Point mobile/capacitor.config.json → server.url at that address, e.g. http://YOUR-PC-IP:3000.
  3. Run npx cap sync and rebuild the app — or just tap retry if it’s already set up.
